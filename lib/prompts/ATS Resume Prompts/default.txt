# ATS prompt variant: default
# INPUT (work history + JD), FIELD GLOSSARY (data contract), and OUTPUT (strict JSON) are composed server-side per profile.

**INSTRUCTIONS**

Read INPUT (work history, job context). Obey FIELD GLOSSARY and OUTPUT for JSON shape. Return ONLY valid JSON per OUTPUT block.

====================================================
METRICS (summary + experience[].details)
====================================================

- **Default:** No exact quantitative metrics — describe outcomes qualitatively (reliability, maintainability, delivery confidence). Do not invent numbers from job context.
- **QA roles:** Quality/automation metrics only if grounded in INPUT screening.notes or role metadata.
- **ML/AI roles:** Model metrics only if grounded in INPUT screening.notes or role metadata.

====================================================
DOMAIN KEYWORDS
====================================================

Extract 10–15 domain keywords from job context (identity, payments, healthcare, data governance, etc.). Use in summary (3–5), skills (dedicated category when relevant), and experience[].details (2–3 bullets per role).

====================================================
TITLE LOGIC
====================================================

Base: most recent role title from INPUT (`{{recentRoleTitle}}`).

Normalize seniority words (Senior, Lead, Junior, etc.) when comparing profile title vs job-context role type.

**If core role types match** (e.g. Full Stack ↔ Full Stack): `{{recentRoleTitle}} | Tech1 | Tech2 | Tech3 | Tech4`

**If they differ** (e.g. profile Full Stack, JD Frontend-only): `{{recentRoleTitle}} | Specialization | Tech1 | Tech2 | Tech3 | Tech4`

Specialization examples: Frontend Specialist, Backend Architect, DevOps Specialist, QA Lead — match JD primary focus.

Extract 4–6 technologies from job context. Separate with ` | `.

====================================================
SUMMARY / SKILLS / EXPERIENCE
====================================================

**summary:** 5–6 full sentences. {{yearsOfExperience}}+ years. 8–12 exact job-context keywords + domain keywords. Complete sentences only.

**skills:** 60–80 total, 5–8 categories, 8–12 per category. Weight toward job-context keywords. No version spam.

**experience:** {{experienceCount}} objects. Job context is primary for keyword alignment; INPUT work history is the authenticity anchor.

{{careerGuidance}}

25–35 words per detail string. Strong verbs. Era-appropriate technology only.

====================================================
ATS CHECKLIST
====================================================

Use exact JD phrases (not synonyms). Required/preferred JD skills must appear in skills. High-priority keywords 3–4× across skills, summary, and experience details. Natural professional tone.

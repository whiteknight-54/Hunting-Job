### **2. `title` (OUTPUT root field)**
- **BASE ROLE TITLE:** Use the candidate's most recent role title from INPUT work history (first profile `experience[]` entry's `title`)
- **CRITICAL RULE - MATCHING LOGIC:** To determine if titles match, normalize both titles by:
  1. Remove seniority indicators: "Senior", "Lead", "Principal", "Staff", "Junior", "Entry-Level" (ignore these words)
  2. Extract core role type: "Full Stack", "Frontend", "Backend", "Software Engineer", "Developer", "Engineer", "Architect", "DevOps", "QA", etc.
  3. Compare core role types - they MATCH if they refer to the same domain/type, even if wording differs slightly

**TITLES MATCH IF:**
- Both are Full Stack roles: "Senior Full Stack Engineer" = "Full Stack Developer" = "Full Stack Software Engineer" = "Full Stack Engineer" → MATCH
- Both are Frontend roles: "Senior Frontend Engineer" = "Frontend Developer" = "Frontend Software Engineer" → MATCH
- Both are Backend roles: "Senior Backend Engineer" = "Backend Developer" = "Backend Software Engineer" → MATCH
- Both are Software Engineer/Developer (general): "Senior Software Engineer" = "Software Developer" = "Senior Developer" → MATCH
- Both are DevOps roles: "Senior DevOps Engineer" = "DevOps Engineer" = "DevOps Specialist" → MATCH

**TITLES DON'T MATCH IF:**
- Profile base is Full Stack, job context is Frontend-only → NO MATCH (add "Frontend Specialist")
- Profile base is Frontend, job context is Backend-only → NO MATCH (add "Backend Specialist")
- Profile base is Backend, job context is Full Stack → NO MATCH (add "Full Stack Experience")
- Profile base is Software Engineer (general), job context is Frontend-specific → NO MATCH (add "Frontend Specialist")

- **If titles MATCH:** OUTPUT `title` format: [Most Recent Role Title] | [Key Tech 1] | [Key Tech 2] | [Key Tech 3] | [Key Tech 4] (NO specialization added)
- **If titles DON'T match:** OUTPUT `title` format: [Most Recent Role Title] | [Job-Related Specialization] | [Key Tech 1] | [Key Tech 2] | [Key Tech 3] | [Key Tech 4]

- **Job-related specialization (ONLY if titles don't match):** Add 1 specialization/role that aligns with job context focus (e.g., if applying for frontend job with full stack profile: "Frontend Specialist" or "Frontend Lead")
  - If job context is frontend-focused → "Frontend Specialist" or "Frontend Lead"
  - If job context is backend-focused → "Backend Specialist" or "Backend Architect"
  - If job context is Full Stack-focused → "Full Stack Developer" or "Full Stack Experience"
  - If job context is DevOps-focused → "DevOps Specialist" or "Infrastructure Lead"
  - If job context is QA-focused → "QA Specialist" or "Quality Assurance Lead"
  - Match the specialization to the job context's primary focus area

- **Tech stack:** Extract 4-6 most important technologies from job context (prioritize: frameworks, tools, platforms, methodologies)
- Separate all items with " | " (space-pipe-space)

- **Examples (OUTPUT `title` value):**
  - Profile `experience[0].title`: "Senior Full Stack Engineer", job context: "Full Stack Developer" → MATCH → "Senior Full Stack Engineer | React | TypeScript | Next.js | AWS"
  - Profile: "Full Stack Software Engineer", job context: "Full Stack Developer" → MATCH → "Full Stack Software Engineer | Java | Python | React.js | GCP"
  - Profile: "Senior Frontend Software Engineer", job context: "Frontend Developer" → MATCH → "Senior Frontend Software Engineer | React | TypeScript | Next.js | AWS"
  - Profile: "Senior Full Stack Engineer", job context: "Frontend Engineer" → NO MATCH → "Senior Full Stack Engineer | Frontend Specialist | React.js | TypeScript | Next.js | AWS"
  - Profile: "Senior Software Engineer", job context: "Backend Engineer" → NO MATCH → "Senior Software Engineer | Backend Architect | Node.js | Python | Microservices | Docker"
  - Profile: "Senior Frontend Engineer", job context: "Full Stack Developer" → NO MATCH → "Senior Frontend Engineer | Full Stack Experience | React.js | Node.js | PostgreSQL | AWS"
